# 千喜萬福｜2026 中華總會會員大會摸彩

工作人員在主控電腦操作，另一個瀏覽器視窗顯示本輪獎項、贊助者與中獎號碼。適用一部電腦連接投影機，以延伸桌面方式操作。現場採每號限中一次，並依獎項扣除剩餘份數。

## 現場操作

1. 在主控電腦以 Chrome 或 Edge 開啟活動網址。用一般瀏覽視窗，正式活動期間持續使用同一個網址和瀏覽器設定檔。
2. 進入「活動設定」，輸入實際發出的摸彩券號碼，例如 `1-350, 401-530, 601`，再按「儲存號碼池」。序號以數值識別，畫面至少顯示四位。未輸入實際號碼前不可開抽。
3. 在「獎項與抽法」選擇獎項。現場抽取請選「系統現場隨機抽出」。如需預設，請選「後台預設號碼」，依開出順序輸入，或填入個數按「加入隨機號碼」，最後按「儲存獎項設定」。預留號碼會從其他獎項可抽的號碼中扣除。
4. 回到「抽獎舞台」，在右側選本輪獎項，輸入本輪名額。按「開啟投影」，將新視窗移到投影機，點「全螢幕投影」。音樂由主控視窗的「背景音樂」開關控制。
5. 按主控台的「千喜萬福」。成功時，投影畫面的號碼牌會跳動，約兩秒後揭曉。每頁最多八個中獎號碼，每七秒輪播一頁，另可手動翻頁。分批開獎時可再次按抽獎鈕。
6. 在「中獎紀錄」按「下載 CSV」保存名單。Excel 如需保留前置零，請以「從文字/CSV」匯入，將「摸彩券號碼」指定為文字欄。
7. 彩排結束後，可展開「彩排後清除紀錄」並按說明確認。此操作清除所有輪次與預留號碼。正式開獎前請另行核對每個預設獎項的號碼。

## 贊助資料與分配

已匯入十五筆贊助。數量明確的十一項暫按每件一個中獎名額，共 774 名；如要合併數件為一份獎，可調整獎品名稱與總名額。楊政達 80,000 元、黃明泰 100,000 元、陳順章 100,000 元與黃敏惠 30,000 元全聯禮券列為待確認。請先確認每份內容，於獎品名稱註明並填入總名額後啟用。維剛的 100,000 元已列為 100 份全聯 1,000 元禮券。

## 電腦與資料保存

投影與控制台須使用同一台電腦、同一瀏覽器及設定檔。工作人員僅將投影視窗拖到延伸螢幕。活動號碼、預設與紀錄保存在該網址的瀏覽器本機儲存空間；清除網站資料會一併清除活動資料。GitHub 用於保存程式原始碼。抽獎音樂由 Web Audio 即時合成，無須外接音樂檔。

## 從原始碼啟動

現場版請先完整解壓縮，使用 Chrome 或 Edge 開啟根目錄的 `Lottery.html`，看到「大會摸彩」即可設定。這是整合樣式與程式的單一網頁，可離線使用。彩排及正式活動請沿用同一個檔案路徑。若電腦限制本機檔案儲存或抽獎鎖定功能，請使用下方的本機網址方式。

網站檔案在 `dist/`，可完整部署在同一路徑的 HTTPS 靜態網站。若現場沒有網路，可事前下載完整資料夾，在裝有 Python 3 的電腦中，於本資料夾開啟終端機執行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

在瀏覽器開啟 `http://127.0.0.1:8765/`，成功時可看到「大會摸彩」主控台。全程保留終端機視窗。若改用此本機網址，請在此網址完成彩排及正式資料的設定。

## 維護與驗證

- `dist/index.html` 定義舞台、設定及紀錄畫面。
- `dist/style.css` 負責主控台與投影樣式。
- `dist/lottery.js` 包含贊助清單、抽樣、預留與名額檢查。
- `dist/app.js` 負責操作介面、瀏覽器儲存、跨視窗同步、音樂及 CSV 匯出。
- 在本資料夾使用 Node.js 22 或以上版本執行 `node --test test.cjs`，成功時所有測試均顯示通過。
